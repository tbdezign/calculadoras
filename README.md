# TBDezign Calculadoras

Calculadoras internas de orçamento da TBDezign.

- `index.html` — página inicial com links para as duas calculadoras
- `apparel.html` — Apparel Quotes (Silk Screen, DTF, Bordado)
- `pricing.html` — Pricing Calculator (cartões, impressos, etiquetas, banners, brindes)

Os produtos ficam no banco Supabase (projeto `tbdezign-calculadoras`), protegido por login.
Nenhum custo ou dado de produto fica neste repositório.
